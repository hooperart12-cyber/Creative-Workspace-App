## Tests actually run

- `npm test` — 36 files, 280 tests, all passed (2026-11-06). Includes field conflicts, revision-checked undo, a rolled-back locked-spread move, Reader close not writing resume, a folder trash that keeps the collection, and a 1,000-page window.
- `npm run lint` — passed.
- `npm run typecheck` — passed.
- `npm run build` — passed. The Windows installer was not built or installed.
- `npx playwright test` — 41 tests passed, including `e2e/collections.spec.ts`. That spec opens the Planner, both layouts, the optional overview, the Reader, and Artwork Review in Electron. It does not import a file, export, drag, resize the inspector, or open a second window. The other 40 tests are the existing canvas, notes, library, tags, stacks, and connection checks.

## Not built

Command palette, a visual crop editor, clipboard, Asset Library, canvas-drop, and M7 slide import, bulk tag or stage edits, per-version relink, collection-local folder matching, and stored damaged or changed-external artwork states. A second application window was not opened. A package uses the existing archive limits. The PDF is built in memory from displayed images. Excluded features stay excluded: no reference workspace, no chapter validation, no page templates, no hierarchical contents, and no per-collection Reader theme.
