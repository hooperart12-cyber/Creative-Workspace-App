## Still open

The OS file, folder, and save dialogs are not driven by Playwright. Clipboard import and This board were not clicked. Folder match shows a confirm list and writes nothing until Confirm match; that dialog was not opened. Changed-external is classified and has a Reader message, and the repository never sets it because artwork is copied into the library. The inspector width slider was not compared across two windows. There is no command palette. A package uses the existing archive limits. The PDF is built in memory from displayed images. Excluded features stay excluded: no reference workspace, no chapter validation, no page templates, no hierarchical contents, and no per-collection Reader theme.

The macOS GitHub Actions job on `3246e31` was cancelled twice before any step ran. That is not a test failure. The Windows check passed. The Windows installer job did not start because it waits for both checks. It has not been installed by hand.
